## Usage

```tsx
import {
  NumberField,
  NumberFieldGroup,
  NumberFieldDecrement,
  NumberFieldInput,
  NumberFieldIncrement,
} from '@acronis-platform/ui-react';
```

`NumberField` is a compound numeric input built on
[Base UI's NumberField](https://base-ui.com/react/components/number-field) —
parsing, clamping, and keyboard stepping (↑/↓, PageUp/PageDown, Home/End) come
from the primitive. `NumberField` is the root and owns `value` / `min` / `max` /
`step`; `NumberFieldGroup` is the bordered box; `NumberFieldDecrement` and
`NumberFieldIncrement` are real `<button>`s that default to a minus / plus icon,
and `NumberFieldInput` is the centered input. There is no `--ui-number-field-*`
token tier: the box reuses the `--ui-input-text-*` tier so it matches
[`InputText`](/components/input-text), and the steppers use the shared
`--ui-text-on-surface-*` / `--ui-background-surface-hover` tokens.

> Status: draft (design-pending v1), ported from the legacy `shadcn-uikit`
> number-field.

## Examples

The steppers sit inside the box on either side of the input. Give each one an
accessible name, and name the input itself — or pair the whole field with a
[`Field`](/components/field) and a `FieldLabel`:

<DemoReact>
  <NumberFieldDemo />
</DemoReact>

```tsx
<NumberField defaultValue={3} min={0} max={99}>
  <NumberFieldGroup>
    <NumberFieldDecrement aria-label="Decrease" />
    <NumberFieldInput aria-label="Quantity" />
    <NumberFieldIncrement aria-label="Increase" />
  </NumberFieldGroup>
</NumberField>
```

Both steppers accept children, so the default icons can be replaced:

```tsx
<NumberFieldDecrement aria-label="Decrease">−</NumberFieldDecrement>
<NumberFieldIncrement aria-label="Increase">+</NumberFieldIncrement>
```

`step` sets what the steppers and arrow keys move by; `largeStep` applies while
Shift is held and `smallStep` while the meta key is. `snapOnStep` snaps to
multiples of `step`:

```tsx
<NumberField
  defaultValue={1.5}
  min={0}
  max={10}
  step={0.5}
  largeStep={2}
  snapOnStep
>
  <NumberFieldGroup>
    <NumberFieldDecrement aria-label="Decrease" />
    <NumberFieldInput aria-label="Weight" />
    <NumberFieldIncrement aria-label="Increase" />
  </NumberFieldGroup>
</NumberField>
```

Format the displayed value with `Intl.NumberFormat` options, and let the wheel
change it while the input is focused and hovered:

```tsx
<NumberField
  defaultValue={49}
  format={{ style: 'currency', currency: 'USD' }}
  allowWheelScrub
>
  {/* …group… */}
</NumberField>
```

Controlled, where the empty input is `null` rather than `0`:

```tsx
const [quantity, setQuantity] = React.useState<number | null>(1);

<NumberField value={quantity} onValueChange={setQuantity} min={1}>
  {/* …group… */}
</NumberField>;
```

`disabled` and `readOnly` both apply to the input and both steppers; the box
picks up its disabled border and surface from the `--ui-input-text-*` tier:

```tsx
<NumberField defaultValue={3} disabled>
  {/* …group… */}
</NumberField>
```

Inside a [`Form`](/components/form), `name` keys the submitted value and
`required` blocks submission while the field is empty. For an approximate value
across a range use [`Slider`](/components/slider); for free text use
[`InputText`](/components/input-text).

### NumberField

`NumberFieldGroup`, `NumberFieldInput`, `NumberFieldDecrement`, and
`NumberFieldIncrement` add no props of their own — each extends the matching Base
UI part (`NumberField.Group` / `.Input` / `.Decrement` / `.Increment`) plus
`className`. The two steppers render their `children` when given, falling back to
the minus / plus icon. Base UI's `NumberField.ScrubArea` is not wrapped here; use
`allowWheelScrub` on the root instead. See the
[Base UI NumberField docs](https://base-ui.com/react/components/number-field) for
the full prop surface.
