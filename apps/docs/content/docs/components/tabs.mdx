## Usage

```tsx
import {
  Tabs,
  TabsList,
  TabsTrigger,
  TabsContent,
} from '@acronis-platform/ui-react';
```

`Tabs` is a compound component built on
[Base UI's Tabs](https://base-ui.com/react/components/tabs), which supplies the
roving focus, arrow-key navigation, and the `tablist` / `tab` / `tabpanel` ARIA
wiring. `Tabs` owns the selected value; `TabsList` holds the `TabsTrigger`s as a
bordered segmented control; each `TabsContent` shows when its `value` matches the
selected tab. A trigger and the panel it controls are paired by sharing the same
`value`.

Design-pending v1, ported from the legacy `shadcn-uikit` tabs. There is no
`--ui-tabs-*` token tier yet, so segments theme from the shared brand tokens: an
idle trigger draws its border and label from the `secondary` bridge (the action
blue, `--ui-background-brand-secondary` — not `primary`, which is the dark navy),
and the active segment renders **filled** — `bg-secondary` with a pure-white
`text-primary-foreground` label, like the default `Button`. The legacy
`bg-primary/10` tint was dropped to avoid an opacity hack; the final treatment
(filled vs. tinted vs. underline) is still to be confirmed. Focus rings use
`--ui-focus-primary`.

Use it to switch between a few peer views of the same area. Don't use it to
navigate between routes (use links or a nav), for sequential steps (use a
wizard/stepper), or for more tabs than fit comfortably in a segmented strip.

## Examples

<DemoReact>
  <TabsDemo />
</DemoReact>

A basic two-tab group:

```tsx
<Tabs defaultValue="account" className="w-[400px]">
  <TabsList className="grid w-full grid-cols-2">
    <TabsTrigger value="account">Account</TabsTrigger>
    <TabsTrigger value="password">Password</TabsTrigger>
  </TabsList>
  <TabsContent value="account">Make changes to your account here.</TabsContent>
  <TabsContent value="password">Change your password here.</TabsContent>
</Tabs>
```

Controlled — drive `value` and react to `onValueChange`:

```tsx
const [tab, setTab] = useState('account');

<Tabs value={tab} onValueChange={setTab}>
  {/* …list + content… */}
</Tabs>;
```

`orientation="vertical"` switches arrow-key navigation to Up/Down:

```tsx
<Tabs defaultValue="account" orientation="vertical">
  {/* … */}
</Tabs>
```

A disabled tab can't be selected and is skipped by arrow-key navigation:

```tsx
<TabsTrigger value="billing" disabled>
  Billing
</TabsTrigger>
```
