## Usage

```tsx
import {
  Card,
  CardHeader,
  CardTitle,
  CardDescription,
  CardContent,
  CardFooter,
} from '@acronis-platform/ui-react';
```

`Card` is a compound component with no variants: a bordered, rounded surface
assembled from parts. `CardHeader` stacks a `CardTitle` and `CardDescription`;
`CardContent` holds the body; `CardFooter` lays out actions in a row. Every part
is optional, renders a `<div>` by default, and shares one prop shape —
`CardPartProps` — including a `render` prop for Base UI composition, so
`CardTitle` can become a real heading and the root an `<article>`.

Design-pending v1, ported from the legacy `shadcn-uikit` card: with no
`--ui-card-*` token tier yet, the surface, text, and border resolve to shared
semantic tokens through the bridged Tailwind names —
`--ui-background-surface-primary`, `--ui-text-on-surface-primary`,
`--ui-border-on-surface-border`, and `--ui-text-on-surface-secondary` for the
description. Radius, padding, gaps, and the shadow carry over from legacy
verbatim; an elevated-surface token may replace the primary surface once a
mockup lands.

Use it to group related information into a self-contained block. For a compact
single-stat tile with built-in variants and interactivity use
[`CardFilter`](/components/card-filter); for modal or overlay surfaces use
[`Dialog`](/components/dialog) / [`Popover`](/components/popover).

A card with a header, body, and footer actions:

```tsx
<Card className="w-[350px]">
  <CardHeader>
    <CardTitle>Backup status</CardTitle>
    <CardDescription>Last successful run 5 minutes ago.</CardDescription>
  </CardHeader>
  <CardContent>
    <p className="text-sm">All 24 workloads are protected and up to date.</p>
  </CardContent>
  <CardFooter className="gap-2">
    <Button>View report</Button>
    <Button variant="secondary">Run now</Button>
  </CardFooter>
</Card>
```

Header and content only — every part is optional:

```tsx
<Card className="w-[350px]">
  <CardHeader>
    <CardTitle>Storage usage</CardTitle>
    <CardDescription>3.2 TB of 5 TB used.</CardDescription>
  </CardHeader>
  <CardContent>
    <p className="text-sm">64% of your quota is currently consumed.</p>
  </CardContent>
</Card>
```

Render the title as a real heading for a correct document outline, and the root
as an `<article>`:

```tsx
<Card render={<article />}>
  <CardHeader>
    <CardTitle render={<h3 />}>Section title</CardTitle>
  </CardHeader>
</Card>
```

## API Reference

Every part (`Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`,
`CardFooter`) shares the same props — the standard `<div>` attributes plus a
`render` prop for Base UI composition.
