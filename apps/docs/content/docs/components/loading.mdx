## Usage

```tsx
import { Loading } from '@acronis-platform/ui-react';
```

`Loading` pairs a spinning ring with an optional label and is themed by the
`--ui-loading-*` tokens — one set per placement context. `variant` picks the
context: `inline` (the default) sits flush in text flow with no container;
`onSurfacePrimary` / `onSurfaceSecondary` are rounded, padded chips for a primary
or secondary app surface; `onScreen` is the higher-contrast dark chip for placing
over a busy photo or video surface. The variant also fixes the ring size (16px
inline, 32px on a surface, 48px on screen).

This is the app-facing standalone loading indicator. The bare
[`Spinner`](/components/spinner) ring it reuses for its icon is an internal
primitive and isn't exported for direct use.

## Examples

The four variants. `onScreen` is shown over a dark backdrop, which is what it's
designed for:

<DemoReact>
  <LoadingDemo />
</DemoReact>

```tsx
<Loading variant="inline" />
<Loading variant="onSurfacePrimary" />
<Loading variant="onSurfaceSecondary" />
<div className="bg-[#191b23] p-6">
  <Loading variant="onScreen" />
</div>
```

The label defaults to `"Data is loading…"`. Override it with `label` to describe
the actual operation:

```tsx
<Loading variant="onSurfacePrimary" label="Fetching your data…" />
```

Set `hasLabel={false}` to hide the text. It is still exposed to assistive
technology as the root's `aria-label`, so the indicator keeps an accessible name:

```tsx
<Loading variant="onScreen" hasLabel={false} label="Rendering preview…" />
```

## Accessibility

The root is `role="status"` — a polite live region. The ring is `aria-hidden`, so
the visible label (or, with `hasLabel={false}`, the root's `aria-label`) is the
single announcement; nothing is announced twice.
