## Usage

```tsx
import { ButtonIcon } from '@acronis-platform/ui-react';
```

`ButtonIcon` renders a square 32px `<button>` with a single 24px glyph centered
in it, styled by the `--ui-button-icon-*` design tokens. The icon is passed as
`children` — nothing is injected. It is polymorphic via Base UI's `useRender` —
pass the `render` prop to render it as another element while keeping the button
styling and merged props.

The control has no text, so always give it an `aria-label` (or
`aria-labelledby`) for its accessible name.

## Examples

Two variants — `ghost` (the default, borderless) and `secondary` (a 1px
container border). Both share the same container fill and glyph colors:

<DemoReact>
  <ButtonIconDemo />
</DemoReact>

```tsx
import {
  PlusIcon,
  PencilIcon,
  CogIcon,
} from '@acronis-platform/icons-react/stroke-mono';

<ButtonIcon variant="ghost" aria-label="Add">
  <PlusIcon />
</ButtonIcon>
<ButtonIcon variant="secondary" aria-label="Edit">
  <PencilIcon />
</ButtonIcon>
<ButtonIcon variant="secondary" aria-label="Settings" disabled>
  <CogIcon />
</ButtonIcon>
```

Disabled state uses dedicated disabled tokens (not opacity) and suppresses the
click:

```tsx
<ButtonIcon aria-label="Edit" disabled>
  <PencilIcon />
</ButtonIcon>
```

Render as another element with `render` (Base UI composition):

```tsx
<ButtonIcon render={<a href="/settings" />} aria-label="Settings">
  <CogIcon />
</ButtonIcon>
```

For an action that needs a text label use [Button](/components/button); for a
compact affordance that sits inside a text field's box use
[ButtonIconInput](/components/button-icon-input).
