## Usage

```tsx
import { Button, DialogFooterDefault, Link } from '@acronis-platform/ui-react';
```

`DialogFooterDefault` is the bottom action bar of a panel, dialog, or sheet. It
lays out end-aligned actions — passed as `children`, typically a secondary and a
primary `Button` — plus an optional start slot: a truncated `description`, or a
`link`. `description` and `link` are **mutually exclusive**; pass at most one.
When neither is set, the actions sit flush to the end.

Figma models this as a `variant` (default / withDescription / withLink), but the
variant is structural rather than a separate prop here: it follows from which
optional slot you pass, the same way `Breadcrumb`'s current page is a distinct
part instead of a duplicated state prop.

Themed by the `--ui-footer-*` tier: `--ui-footer-global-height` for the bar
height, `--ui-footer-global-padding-x` and `--ui-footer-global-gap` for spacing,
`--ui-footer-default-color` for the surface, and
`--ui-footer-default-border-color` / `-border-width` for the top divider.

Use it for the bottom action row of a panel/dialog/sheet, including when the
actions need brief accompanying context or a related link. For a bulk-action or
selection bar above a list or table use [`Toolbar`](/components/toolbar); for a
full app-level bottom bar, compose the layout directly.

## Examples

<DemoReact>
  <DialogFooterDefaultDemo />
</DemoReact>

Actions only — flush to the trailing edge:

```tsx
<DialogFooterDefault>
  <Button variant="secondary">Cancel</Button>
  <Button>Save</Button>
</DialogFooterDefault>
```

With a `description` — truncated with an ellipsis when the bar is too narrow:

```tsx
<DialogFooterDefault description="Changes are saved automatically as you type.">
  <Button variant="secondary">Cancel</Button>
  <Button>Save</Button>
</DialogFooterDefault>
```

With a `link` in the start slot instead:

```tsx
<DialogFooterDefault link={<Link href="/docs">Learn more</Link>}>
  <Button variant="secondary">Cancel</Button>
  <Button>Save</Button>
</DialogFooterDefault>
```
