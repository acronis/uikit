## Usage

```tsx
import { ButtonMenu } from '@acronis-platform/ui-react';
```

`ButtonMenu` renders a Button-like `<button>` — your label followed by a 16px
chevron it appends itself — styled by the `--ui-button-menu-*` design tokens.
It is polymorphic via Base UI's `useRender`, so the `render` prop can turn it
into the trigger of the menu it opens.

`ButtonMenu` owns only the trigger; the popup is yours. Keep `open` in sync
with that popup's state: it flips the chevron down → up, applies the open
(`*-active`) treatment, and reflects `aria-expanded`.

## Examples

Two variants — `primary` (the default, solid) and `secondary` (bordered with a
transparent fill). The third button below is `open`, the fourth `disabled`:

<DemoReact>
  <ButtonMenuDemo />
</DemoReact>

```tsx
<ButtonMenu variant="primary">Actions</ButtonMenu>
<ButtonMenu variant="secondary">Filter</ButtonMenu>
<ButtonMenu variant="secondary" open>
  Sort by
</ButtonMenu>
<ButtonMenu variant="primary" disabled>
  Export
</ButtonMenu>
```

Wire `open` to the state of the menu you control:

```tsx
const [open, setOpen] = React.useState(false);

<ButtonMenu open={open} onClick={() => setOpen((v) => !v)}>
  Sort by
</ButtonMenu>
```

With [DropdownMenu](/components/dropdown-menu), pass the button to
`DropdownMenuTrigger`'s `render` prop. The menu owns the ARIA wiring and
dismissal; control its `open` state so you can hand the same value to
`ButtonMenu` and keep the chevron in step:

```tsx
const [open, setOpen] = React.useState(false);

<DropdownMenu open={open} onOpenChange={setOpen}>
  <DropdownMenuTrigger
    render={
      <ButtonMenu variant="secondary" open={open}>
        Actions
      </ButtonMenu>
    }
  />
  <DropdownMenuContent>{/* DropdownMenuItem… */}</DropdownMenuContent>
</DropdownMenu>
```

Disabled state uses dedicated disabled tokens (not opacity):

```tsx
<ButtonMenu disabled>Actions</ButtonMenu>
```

For a plain action with no menu use [Button](/components/button); to pick one
option from a list and show the chosen value use
[InputSelect](/components/input-select).
