## Usage

```tsx
import {
  Breadcrumb,
  BreadcrumbList,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbPage,
  BreadcrumbSeparator,
  BreadcrumbEllipsis,
} from '@acronis-platform/ui-react';
```

`Breadcrumb` renders a `<nav aria-label="breadcrumb">` landmark around an
ordered trail, kept as explicit compound parts so the hierarchy stays visible in
markup. Nest a single `BreadcrumbList` (`<ol>`) of `BreadcrumbItem` (`<li>`)
parts, each holding either a `BreadcrumbLink` (a navigable ancestor) or a
`BreadcrumbPage` (the current page, always last), with `BreadcrumbSeparator`
between them.

Colors come from the `--ui-breadcrumb-*` token tier: links use
`--ui-breadcrumb-link-label-color-idle` and darken through the `-hover` /
`-active` tokens, the current page uses `--ui-breadcrumb-page-label-color`, and
the chevron uses `--ui-breadcrumb-separator-icon-color` at
`--ui-breadcrumb-separator-icon-size`. The inter-item gap is
`--ui-breadcrumb-list-gap`. The default chevron flips under `dir="rtl"`.

`Breadcrumb` and `BreadcrumbLink` are polymorphic via Base UI's `useRender` (the
`render` prop) — pass a router link for client-side navigation.

Use it to orient users inside a multi-level hierarchy, especially when they
arrive by deep link or search. Skip it for flat or single-level navigation; use a
Stepper for wizards and [`Tabs`](/components/tabs) for sibling views.

## Examples

  <BreadcrumbDemo />

A typical trail — links for the ancestors, `BreadcrumbPage` for the leaf:

```tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="#">Home</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbLink href="#">Products</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Settings</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

Truncation is author-driven: collapse the middle items yourself and drop a
`BreadcrumbEllipsis` in their place, keeping the first and last visible.

```tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="#">Home</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbEllipsis />
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Current</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

Pass `children` to `BreadcrumbSeparator` to replace the default chevron:

```tsx
<BreadcrumbSeparator>/</BreadcrumbSeparator>
```

Render a link as a router link with `render`:

```tsx
import { Link as RouterLink } from 'react-router';

<BreadcrumbLink render={<RouterLink to="/products" />}>
  Products
</BreadcrumbLink>;
```
