## Usage

```tsx
import { Progress } from '@acronis-platform/ui-react';
```

`Progress` wraps Base UI's `Progress` primitive (`Root` → `Track` →
`Indicator`) as an 8px full-width rail with a rounded fill. The root carries
`role="progressbar"` and the ARIA value range derived from `value` / `min` /
`max`. Pass a `value` for a determinate bar; omit it (or pass `null`) for an
indeterminate sliding bar.

> Design-pending v1, ported from the legacy `shadcn-uikit` progress. There is no
> `--ui-progress-*` tier yet: the track uses the shared border token via
> `bg-input` and the fill the brand action blue via `bg-secondary`.

## Examples

Determinate bars plus an indeterminate one. The bar has no intrinsic width — it
fills its container, so set the width on the wrapper (or via `className`):

<DemoReact>
  <ProgressDemo />
</DemoReact>

```tsx
<div className="flex w-80 flex-col gap-4">
  <Progress value={25} />
  <Progress value={50} />
  <Progress value={75} />
  <Progress value={null} />
</div>
```

When `value` is `null`, Base UI sets `data-indeterminate` on the indicator, which
swaps the determinate width transition for the sliding `indeterminate-progress`
keyframe. `<Progress />` with no `value` is the same thing:

```tsx
<Progress />
<Progress value={null} />
```

Use `min` / `max` when your scale isn't 0–100:

```tsx
<Progress value={7} max={12} />
```

For an in-progress operation with no measurable length, prefer
[`Loading`](/components/loading). For a percentage shown in a compact circle, use
[`ProgressCircle`](/components/progress-circle); for a bar that grades a value
against thresholds, use [`Meter`](/components/meter).
