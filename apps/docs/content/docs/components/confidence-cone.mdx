## Usage

```tsx
import { ConfidenceCone } from '@acronis-platform/ui-react';
import type { ChartConfig } from '@acronis-platform/ui-react';
```

`ConfidenceCone` is a typed recharts composition over the shared
[`Chart`](/components/chart) primitives that plots a projection with **explicit
uncertainty**: a solid line and filled area over the known/actual period, a dashed
line over the forecast, and a shaded band (the "cone") between a lower and an upper
bound that typically widens with the horizon. A dashed divider and a subtle shaded
region set the forecast off from the actuals. You point the field-name props at your
columns (`xKey`, `actualKey`, `forecastKey`, `lowerKey`, `upperKey`) and never
hand-compose recharts children.

The whole metric renders in **one hue** — actual and forecast differ by line style,
not color — so the cone band and the forecast line both reuse the actual series'
`config` color. The band itself is a synthetic series drawn behind the lines and kept
out of the tooltip and legend, including any tooltip you supply. Avoid a data field
named `__cone`; it's reserved for that internal series.

Use it when the plausible range matters as much as the point estimate: capacity,
license, or revenue forecasts. For a plain trend with no forecast use
[`LineChart`](/components/line-chart), which also covers comparison overlays and
delta bands. Despite the similar silhouette,
[`FunnelChart`](/components/funnel-chart) is a different thing — stage-by-stage
conversion, not a projection.

Pair the chart with a text alternative — a caption or an adjacent table carrying the
actual, forecast, and bound values — and give it an accessible name via `aria-label`
/ `aria-labelledby` (native attributes pass through to the wrapper element). Keep
the legend or tooltip on so actual vs forecast is labelled: the dashed line is a
redundant cue, not the only distinction.

> **Design-pending v1**, built net-new (there is no demo playground for it). There is
> no chart token tier yet, so the metric color references a shared semantic `--ui-*`
> brand token — a dedicated `--ui-chart-*` data-viz palette is pending an upstream
> design pass. The actual area and the cone band reuse that color at low opacity, so
> check its contrast against the surface.

## Examples

<DemoReact>
  <ConfidenceConeDemo />
</DemoReact>

Rows are naturally sparse: a point carries either an actual or a forecast plus its
bounds. Give the hand-off point **both** an `actual` and a `forecast`, with
`lower = upper`, so the cone starts at a point and the two lines meet:

```tsx
const data = [
  { month: 'Apr', actual: 130 },
  { month: 'May', actual: 141 },
  { month: 'Jun', actual: 150, forecast: 150, lower: 150, upper: 150 }, // hand-off
  { month: 'Jul', forecast: 162, lower: 150, upper: 176 },
  { month: 'Aug', forecast: 173, lower: 154, upper: 196 },
];

const config = {
  actual: { label: 'Actual', color: 'var(--ui-background-brand-secondary)' },
  forecast: { label: 'Forecast', color: 'var(--ui-background-brand-secondary)' },
} satisfies ChartConfig;

<ConfidenceCone
  config={config}
  data={data}
  xKey="month"
  actualKey="actual"
  forecastKey="forecast"
  lowerKey="lower"
  upperKey="upper"
  className="h-[320px] w-[560px]"
/>;
```

`showForecastRegion` (on by default) draws the dashed divider at the hand-off plus
the shaded region behind the forecast. Set it to `false` to remove both and let the
cone alone mark the projection:

```tsx
<ConfidenceCone
  config={config}
  data={data}
  xKey="month"
  actualKey="actual"
  forecastKey="forecast"
  lowerKey="lower"
  upperKey="upper"
  showForecastRegion={false}
/>
```

Rows without a numeric `lower` and `upper` are simply left un-coned, which is how
the actual-only period renders no band. Tune the lines with `strokeWidth`, and drop
the chrome with `showGrid` / `showTooltip` / `showLegend`:

```tsx
<ConfidenceCone
  config={config}
  data={data}
  xKey="month"
  actualKey="actual"
  forecastKey="forecast"
  lowerKey="lower"
  upperKey="upper"
  strokeWidth={3}
  showGrid={false}
/>
```

Add axis titles and a y-axis unit suffix with `xAxisLabel` / `yAxisLabel` / `yUnit`
(the x-axis is categorical). The titles inherit the theme token:

```tsx
<ConfidenceCone
  config={config}
  data={data}
  xKey="month"
  actualKey="actual"
  forecastKey="forecast"
  lowerKey="lower"
  upperKey="upper"
  xAxisLabel="Month"
  yAxisLabel="Revenue"
  yUnit="k"
/>
```

Replace the tooltip with a configured `ChartTooltipContent` — imported from the
same library, so you still never compose recharts yourself. The synthetic cone band
is filtered out of the payload before your tooltip sees it, so a `__cone` item never
reaches your formatter:

```tsx
import { ConfidenceCone, ChartTooltipContent } from '@acronis-platform/ui-react';

<ConfidenceCone
  config={config}
  data={data}
  xKey="month"
  actualKey="actual"
  forecastKey="forecast"
  lowerKey="lower"
  upperKey="upper"
  tooltipContent={
    <ChartTooltipContent
      labelFormatter={(label) => `${label} · projection`}
      formatter={(value, name) => `${name}: ${value.toLocaleString()}`}
    />
  }
/>;
```
