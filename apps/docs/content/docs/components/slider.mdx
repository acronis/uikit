## Usage

```tsx
import { Slider } from '@acronis-platform/ui-react';
```

`Slider` is a single component — the control, track, filled indicator, and thumbs
are rendered internally — built on
[Base UI's Slider](https://base-ui.com/react/components/slider). The thumb count
follows the length of `value` / `defaultValue`, so an array renders a range. There
is no `--ui-slider-*` token tier yet: the rail uses
`--ui-border-on-surface-border`, the filled indicator and the thumb border use the
brand action color `--ui-background-brand-secondary`, and the focus/drag ring uses
`--ui-focus-primary`. Only the horizontal layout is styled. Give the slider an
accessible name with `aria-label`, or pair it with a [`Field`](/components/field)
and a `FieldLabel`.

> Status: draft (design-pending v1), ported from the legacy `shadcn-uikit` slider.

## Examples

A single value and a two-thumb range — `Slider` normalizes a plain number into a
one-entry array before handing it to Base UI:

<DemoReact>
  <SliderDemo />
</DemoReact>

```tsx
<Slider defaultValue={40} aria-label="Volume" />
<Slider defaultValue={[20, 80]} aria-label="Price range" />
```

Bound and quantize the range with `min` / `max` / `step`. `largeStep` is what
PageUp/PageDown and Shift+Arrow move by:

```tsx
<Slider
  defaultValue={2}
  min={0}
  max={10}
  step={0.5}
  largeStep={2}
  aria-label="Rating"
/>
```

Controlled, with `onValueChange`. Because the wrapper always passes an array to
Base UI, the callback receives an array even for a single-value slider:

```tsx
const [values, setValues] = React.useState([40]);

<Slider value={values} onValueChange={setValues} aria-label="Volume" />;
```

On a range, `minStepsBetweenValues` keeps a gap between the thumbs and
`thumbCollisionBehavior` decides what happens when they meet:

```tsx
<Slider
  defaultValue={[20, 80]}
  minStepsBetweenValues={10}
  thumbCollisionBehavior="none"
  aria-label="Price range"
/>
```

Disabled repoints the fill and the thumb border to a neutral gray
(`--ui-background-status-strong-neutral`) and dims the thumb:

```tsx
<Slider defaultValue={40} disabled aria-label="Volume" />
```

For precise numeric entry use [`NumberField`](/components/number-field) or
[`InputText`](/components/input-text); for a handful of discrete choices use
[`Radio`](/components/radio) or [`ToggleGroup`](/components/toggle-group).
