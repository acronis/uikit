## Usage

```tsx
import { Metric } from '@acronis-platform/ui-react';
```

`Metric` is a presentational metric card modelled on the dashboard MetricCard
design: a label (+ optional caption) over a primary value — with an optional
status-tinted icon badge, unit, and trend — plus an optional body for a chart,
breakdown, or insight. It is purely presentational: the consumer passes a
ready-formatted `value` and a resolved `status`; the kit never computes or
formats the value, converts units, or decides whether a value is good or bad.

A simple metric with a unit, status, and a composed `TrendIndicator`:

```tsx
<Metric
  label="Endpoint coverage"
  value="94"
  unit="%"
  status="success"
  icon={<ChartPieIcon />}
  supportingText="Target: 98%"
  trend={<TrendIndicator direction="up" sentiment="positive" value="2%" size="small" />}
/>
```

Metric is a Card, so drop a chart, a `Meter` breakdown, a `Separator`, or an
insight line into its `children` to build a full dashboard tile:

```tsx
<Metric
  label="At-risk customers"
  status="critical"
  icon={<ChartPieIcon />}
  caption={<Tag>Now</Tag>}
  value="3"
  trend={<TrendIndicator direction="up" sentiment="negative" value="1" size="small" />}
>
  <Meter label="Healthy" value={46} max={54} color="var(--ui-background-status-strong-success)" showTooltip={false} />
  <Meter label="At risk" value={3} max={54} color="var(--ui-background-status-strong-critical)" showTooltip={false} />
  <Separator className="my-3" />
  <p>+3 customers predicted at-risk within 30 days.</p>
</Metric>
```

`status` (`neutral`, `info`, `success`, `warning`, `danger`, `critical`) tints
the **icon badge** only — the `--ui-background-status-<status>-pressed` fill with
the `--ui-text-on-status-<status>` icon color — a subtle cue, never a full color
fill, so many metrics read calmly together. No data is `value="—"`, not `0`.
