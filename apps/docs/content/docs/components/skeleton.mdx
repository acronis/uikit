## Usage

```tsx
import { Skeleton } from '@acronis-platform/ui-react';
```

`Skeleton` renders a `<div>` with a pulse animation that reserves layout space
while content loads, reducing layout shift. It has no size of its own — width,
height, and radius come from the `className` you pass. The fill is the
`--ui-background-surface-active` gray, chosen over the near-invisible
`--ui-background-surface-secondary` so the placeholder reads on a white surface
and stays subtle in dark mode.

> Design-pending v1, ported from the legacy `shadcn-uikit` skeleton. It has no
> dedicated `--ui-skeleton-*` tier yet.

## Examples

Compose several skeletons into the shape of the content they stand in for — here
an avatar plus two lines of text:

<DemoReact>
  <SkeletonDemo />
</DemoReact>

```tsx
<div className="flex items-center gap-4">
  <Skeleton className="size-12 rounded-full" />
  <div className="flex flex-col gap-2">
    <Skeleton className="h-4 w-[250px]" />
    <Skeleton className="h-4 w-[200px]" />
  </div>
</div>
```

For indeterminate work with no known shape use [`Loading`](/components/loading);
for determinate progress use [`Progress`](/components/progress) or
[`ProgressCircle`](/components/progress-circle). For an empty result set rather
than a pending one, use [`Empty`](/components/empty).
