## Usage

```tsx
import { RadarChart } from '@acronis-platform/ui-react';
import type { ChartConfig } from '@acronis-platform/ui-react';
```

`RadarChart` is a typed composition over the shared [`Chart`](/components/chart)
primitives. Give it `data`, a per-series `config`, the series to plot
(`dataKeys`), and the angular axis key (`angleKey`) — it renders a themed recharts
radar (polar grid, spoke labels, tooltip, legend included), so you don't
hand-compose recharts children.

Series are columns of a shared row (like a bar or line chart), plotted over one
polar angular axis. Series colors are supplied by the caller through `config`:
each entry maps a data key to a `label` and a `color`, turned into the
`--color-<key>` custom properties the areas stroke and fill from.

> **Design-pending v1**, ported from the demo `RadarChartPlayground`. There is no
> chart token tier yet, so the example colors reference the shared brand/status
> tokens — a dedicated `--ui-chart-*` data-viz palette is pending an upstream
> design pass. `--ui-background-status-strong-*` is chromatic in every brand;
> `--ui-background-brand-secondary` is brand-dependent, so it is not color-stable
> across brands until the real palette lands.

## Examples

<DemoReact>
  <RadarChartDemo />
</DemoReact>

Two series compared across shared axes, with a themed tooltip and legend:

```tsx
const data = [
  { subject: 'Math', alice: 120, bob: 110 },
  { subject: 'English', alice: 86, bob: 130 },
  { subject: 'Physics', alice: 85, bob: 90 },
  { subject: 'History', alice: 65, bob: 85 },
];

const config = {
  alice: { label: 'Alice', color: 'var(--ui-background-brand-secondary)' },
  bob: { label: 'Bob', color: 'var(--ui-background-status-strong-danger)' },
} satisfies ChartConfig;

<RadarChart
  config={config}
  data={data}
  dataKeys={['alice', 'bob']}
  angleKey="subject"
  className="h-[380px] w-[420px]"
/>;
```

Draw the web as smooth circles instead of straight polygon rings with
`gridType="circle"`:

```tsx
<RadarChart config={config} data={data} dataKeys={['alice', 'bob']} angleKey="subject" gridType="circle" />
```

Tune the areas with `fillOpacity` / `strokeWidth` / `showDots`, and toggle the
chrome with `showGrid` / `showTooltip` / `showLegend`.

## Custom tooltip

Replace the tooltip with a configured `ChartTooltipContent` — imported from the
same library, so you never compose recharts yourself. Its `formatter` renders
each row and `labelFormatter` the header, giving you custom formatting, per-series
content, and extra fields:

```tsx
import { RadarChart, ChartTooltipContent } from '@acronis-platform/ui-react';

<RadarChart
  config={config}
  data={data}
  dataKeys={['alice', 'bob']}
  angleKey="subject"
  tooltipContent={
    <ChartTooltipContent
      formatter={(value, name) => `${name}: ${value.toLocaleString()}`}
    />
  }
/>;
```

## Animation

Charts render statically by default. Opt in to an entrance animation with
`animate`, and tune it with `animationDuration` / `animationBegin` /
`animationEasing`:

```tsx
<RadarChart config={config} data={data} dataKeys={['alice']} angleKey="subject" animate animationDuration={800} animationEasing="ease-out" />
```

`animate` honors `prefers-reduced-motion`: for a visitor who has asked their
system to reduce motion, the series render at their final geometry with no
animation (the same applies when rendering on the server).

## Data labels

Annotate each point with its value using `showLabels`. `labelFormatter` takes the
same formatters as the axes, so a label and its axis read alike:

```tsx
<RadarChart config={config} data={data} dataKeys={['alice']} angleKey="subject" showLabels labelFormatter={formatCompactNumber} />
```

`labelPosition` moves them; the default is the series' growing end (`top`, or
`right` for horizontal bars). Under `layout="stacked"` that end is covered by the
next segment, so each value centres inside its own segment instead — and switches
to a token that stays legible over the fill:

```tsx
<RadarChart config={config} data={data} dataKeys={['alice']} angleKey="subject" showLabels labelPosition="insideEnd" />
```

Labels are off by default — with more than one series they collide easily, so turn
them on for a single series or a chart with room to spare.
