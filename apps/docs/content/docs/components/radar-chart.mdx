## Usage

```tsx
import { RadarChart } from '@acronis-platform/ui-react';
import type { ChartConfig } from '@acronis-platform/ui-react';
```

`RadarChart` is a typed composition over the shared [`Chart`](/components/chart)
primitives. Give it `data`, a per-series `config`, the series to plot
(`dataKeys`), and the angular axis key (`angleKey`) — it renders a themed recharts
radar (polar grid, spoke labels, tooltip, legend included), so you don't
hand-compose recharts children.

Series are columns of a shared row (like a bar or line chart), plotted over one
polar angular axis. Series colors are supplied by the caller through `config`:
each entry maps a data key to a `label` and a `color`, turned into the
`--color-<key>` custom properties the areas stroke and fill from.

> **Design-pending v1**, ported from the demo `RadarChartPlayground`. There is no
> chart token tier yet, so the example colors reference the shared brand/status
> tokens — a dedicated `--ui-chart-*` data-viz palette is pending an upstream
> design pass. `--ui-background-status-strong-*` is chromatic in every brand;
> `--ui-background-brand-secondary` is brand-dependent, so it is not color-stable
> across brands until the real palette lands.

## Examples

<DemoReact>
  <RadarChartDemo />
</DemoReact>

Two series compared across shared axes, with a themed tooltip and legend:

```tsx
const data = [
  { subject: 'Math', alice: 120, bob: 110 },
  { subject: 'English', alice: 86, bob: 130 },
  { subject: 'Physics', alice: 85, bob: 90 },
  { subject: 'History', alice: 65, bob: 85 },
];

const config = {
  alice: { label: 'Alice', color: 'var(--ui-background-brand-secondary)' },
  bob: { label: 'Bob', color: 'var(--ui-background-status-strong-danger)' },
} satisfies ChartConfig;

<RadarChart
  config={config}
  data={data}
  dataKeys={['alice', 'bob']}
  angleKey="subject"
  className="h-[380px] w-[420px]"
/>;
```

Draw the web as smooth circles instead of straight polygon rings with
`gridType="circle"`:

```tsx
<RadarChart config={config} data={data} dataKeys={['alice', 'bob']} angleKey="subject" gridType="circle" />
```

Tune the areas with `fillOpacity` / `strokeWidth` / `showDots` (sized by
`dotRadius`), and toggle the chrome with `showGrid` / `showTooltip` /
`showLegend`. `legendPosition="top"` moves the legend row above the chart.

## The value scale

A radar has no scale of its own by default: recharts stretches the web so the
largest value in the data touches the outer ring, which makes an area readable
only against its neighbours — two charts of the same metric aren't comparable.
`showRadiusAxis` draws the scale, and `radiusAxisDomain="fixed"` with
`radiusAxisDomainMax` pins the outer ring to the metric's own maximum, so the
areas read as absolute profiles:

```tsx
<RadarChart
  config={config}
  data={data}
  dataKeys={['alice', 'bob']}
  angleKey="subject"
  showRadiusAxis
  radiusAxisAngle={90}
  radiusAxisDomain="fixed"
  radiusAxisDomainMax={150}
  radiusAxisTickCount={4}
/>;
```

`radiusAxisAngle` rotates the scale — point it along a spoke, or between two, so
its ticks don't sit over the areas. `radiusAxisOrientation` picks the side its
labels sit on.

The domain applies whether or not the scale is drawn, so a chart can be scaled to
a known maximum without showing the ticks:

```tsx
<RadarChart config={config} data={data} dataKeys={['alice']} angleKey="subject" radiusAxisDomain="fixed" radiusAxisDomainMax={150} />
```

For a metric where less is better (latency, error rate), `radiusAxisReversed`
puts the maximum at the centre so a good profile still reads as a large area.

## Grid and angle axis

`radialLines={false}` drops the web's spokes and keeps its concentric rings.
The categorical axis around the web is configurable too — `angleAxisOrientation`
moves its labels inside the web, `angleAxisLineType` matches its outline to a
circular grid, and `angleAxisLine` / `angleTickLine` / `angleTickSize` control the
rest:

```tsx
<RadarChart
  config={config}
  data={data}
  dataKeys={['alice', 'bob']}
  angleKey="subject"
  gridType="circle"
  angleAxisLineType="circle"
  angleAxisOrientation="inner"
  angleTickLine={false}
/>;
```

`showAngleAxis={false}` hides all of that chrome at once. The axis itself stays —
it's also what names each category — so the tooltip keeps its header.

## Geometry

`cx` / `cy` move the centre, `startAngle` / `endAngle` rotate the sweep,
`innerRadius` / `outerRadius` size the web (an inner radius separates the series
where they all bottom out), and `margin` insets the plot area:

```tsx
<RadarChart
  config={config}
  data={data}
  dataKeys={['alice', 'bob']}
  angleKey="subject"
  innerRadius={40}
  outerRadius="70%"
  startAngle={45}
  endAngle={-315}
/>;
```

## Per-series styling

`seriesSettings` overrides the chart-level styling for one series, keyed by its
`dataKeys` entry — `color`, `stroke`, `fillOpacity`, `strokeWidth`, `dot`,
`dotRadius`, and `activeDot`. Every series not named keeps the chart-level
values, and an overridden `color` carries into that series' legend swatch and
tooltip indicator:

```tsx
<RadarChart
  config={config}
  data={data}
  dataKeys={['alice', 'bob']}
  angleKey="subject"
  seriesSettings={{
    alice: { fillOpacity: 0.05, strokeWidth: 3, dot: true, dotRadius: 4 },
  }}
/>;
```

Every plotted series needs a value in every row. recharts places a missing one at
the centre of the web rather than leaving a hole, so it reads as a zero — drop the
whole category row instead of leaving a series' value out of it.

## Custom tooltip

Replace the tooltip with a configured `ChartTooltipContent` — imported from the
same library, so you never compose recharts yourself. Its `formatter` renders
each row and `labelFormatter` the header, giving you custom formatting, per-series
content, and extra fields:

```tsx
import { RadarChart, ChartTooltipContent } from '@acronis-platform/ui-react';

<RadarChart
  config={config}
  data={data}
  dataKeys={['alice', 'bob']}
  angleKey="subject"
  tooltipContent={
    <ChartTooltipContent
      formatter={(value, name) => `${name}: ${value.toLocaleString()}`}
    />
  }
/>;
```

## Animation

Charts render statically by default. Opt in to an entrance animation with
`animate`, and tune it with `animationDuration` / `animationBegin` /
`animationEasing`:

```tsx
<RadarChart config={config} data={data} dataKeys={['alice']} angleKey="subject" animate animationDuration={800} animationEasing="ease-out" />
```

`animate` honors `prefers-reduced-motion`: for a visitor who has asked their
system to reduce motion, the series render at their final geometry with no
animation (the same applies when rendering on the server).

## Data labels

Annotate each point with its value using `showLabels`. `labelFormatter` takes the
same formatters as the axes, so a label and its axis read alike:

```tsx
<RadarChart config={config} data={data} dataKeys={['alice']} angleKey="subject" showLabels labelFormatter={formatCompactNumber} />
```

`labelPosition` moves them; the default is `top`, which sits each value above its
vertex on the chart surface. An `inside*` position draws it over the area's fill
instead, and switches to a token that stays legible there:

```tsx
<RadarChart config={config} data={data} dataKeys={['alice']} angleKey="subject" showLabels labelPosition="insideEnd" />
```

Labels are off by default — with more than one series they collide easily, so turn
them on for a single series or a chart with room to spare.
