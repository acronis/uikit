## Usage

```tsx
import { ScatterChart } from '@acronis-platform/ui-react';
import type { ChartConfig } from '@acronis-platform/ui-react';
```

`ScatterChart` is a typed recharts composition over the shared
[`Chart`](/components/chart) primitives. Give it a `series` list (each entry a
`{ key, data }` pair with its own points), a per-series `config`, and the numeric
axis fields (`xKey` / `yKey`) — it renders a themed recharts scatter chart with
tooltip, legend, axes, and grid, so you never hand-compose recharts children. Add
a `zKey` to size points by a third field (a bubble chart).

Each series carries its **own** point array — points aren't columns of a shared row
the way bar, line, and area series are — so the API takes a `series` list rather
than `dataKeys`. Series colors are supplied by the caller through `config`, keyed
by each `series[].key`: `ScatterChart` turns those into the `--color-<key>` custom
properties its points fill from.

Use it to show the relationship or correlation between two numeric variables, to
reveal clusters and outliers across groups (one `series` entry per group), or to
add a third dimension via point size. For a trend over an ordered dimension use
[`LineChart`](/components/line-chart) or [`AreaChart`](/components/area-chart); for
a quantity across discrete categories, [`BarChart`](/components/bar-chart); for
part-to-whole, [`PieChart`](/components/pie-chart); for the distribution of one
variable, [`Histogram`](/components/histogram).

Pair the chart with a text alternative (caption, summary, or adjacent data table)
and give it an accessible name — `aria-label` / `aria-labelledby` pass through to
the wrapper element. Keep either the legend or the tooltip visible, and use
`shape` as a second, non-color channel when series overlap. **For a bubble chart,
state the size encoding in the caption** — area is imprecise and assistive
technology can't infer it.

> **Design-pending v1**, ported from the demo `ScatterChartPlayground`. There is
> no chart token tier yet, so the example colors reference the shared semantic
> `--ui-*` brand/status tokens — a dedicated `--ui-chart-*` data-viz palette is
> pending an upstream design pass. `--ui-background-status-strong-*` is chromatic
> in every brand; `--ui-background-brand-secondary` is brand-dependent, so it is
> not color-stable across brands until the real palette lands.

## Examples

<DemoReact>
  <ScatterChartDemo />
</DemoReact>

Two groups plotted on shared x/y axes, with a themed tooltip and legend:

```tsx
const series = [
  { key: 'classA', data: [{ hours: 2, score: 55 }, { hours: 6, score: 78 }] },
  { key: 'classB', data: [{ hours: 1, score: 70 }, { hours: 9, score: 95 }] },
];

const config = {
  classA: { label: 'Class A', color: 'var(--ui-background-brand-secondary)' },
  classB: { label: 'Class B', color: 'var(--ui-background-status-strong-danger)' },
} satisfies ChartConfig;

<ScatterChart
  config={config}
  series={series}
  xKey="hours"
  yKey="score"
  className="h-[360px] w-[520px]"
/>;
```

Pass a single `series` entry for an ungrouped scatter:

```tsx
<ScatterChart config={config} series={[series[0]]} xKey="hours" yKey="score" showLegend={false} />
```

Turn it into a bubble chart by mapping a third numeric field to point size with
`zKey`. `zRange` is the `[min, max]` size the values map into; without a `zKey`
every point uses recharts' fixed default size:

```tsx
<ScatterChart config={config} series={series} xKey="hours" yKey="score" zKey="weight" zRange={[60, 500]} />
```

Change the marker with `shape` — `circle` (default), `cross`, `diamond`, `square`,
`star`, `triangle`, or `wye` — and toggle the chrome with `showGrid` /
`showTooltip` / `showLegend`:

```tsx
<ScatterChart config={config} series={series} xKey="hours" yKey="score" shape="triangle" showGrid={false} />
```

Add axis titles and unit suffixes with `xAxisLabel` / `yAxisLabel` / `xUnit` /
`yUnit` — both axes are numeric here, so both units apply. The titles inherit the
theme token:

```tsx
<ScatterChart
  config={config}
  series={series}
  xKey="hours"
  yKey="score"
  xAxisLabel="Hours studied"
  yAxisLabel="Score"
  yUnit="%"
/>
```

Replace the tooltip with a configured `ChartTooltipContent` — imported from the
same library, so you still never compose recharts yourself. Its `formatter`
renders each row and `labelFormatter` the header:

```tsx
import { ScatterChart, ChartTooltipContent } from '@acronis-platform/ui-react';

<ScatterChart
  config={config}
  series={series}
  xKey="hours"
  yKey="score"
  tooltipContent={
    <ChartTooltipContent
      hideLabel
      formatter={(value, name) => `${name}: ${value.toLocaleString()}`}
    />
  }
/>;
```
