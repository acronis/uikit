## Usage

```tsx
import {
  Select,
  SelectTrigger,
  SelectValue,
  SelectContent,
  SelectItem,
  SelectGroup,
  SelectGroupLabel,
} from '@acronis-platform/ui-react';
```

`Select` is a set of aliases for the [`InputSelect`](/components/input-select)
parts, so it is the same Base UI
[`Select`](https://base-ui.com/react/components/select) composition themed by the
`--ui-input-select-*` tokens: `Select` → `InputSelect`, `SelectGroup` →
`InputSelectSection`, `SelectGroupLabel` → `InputSelectSectionLabel`, and the
trigger / value / content / item names map one-to-one. The alias set is the bare
control — it has no label, description, or error part, so give the trigger an
accessible name. **Prefer importing `InputSelect*` directly in new code**;
`Select` exists for compatibility, and only the `InputSelect*` names cover the
field furniture, in-dropdown search, expander, and status rows.

## Examples

A single-select with a preselected value. `items` lets `SelectValue` render the
selected option's label while the popup is closed:

<DemoReact>
  <SelectDemo />
</DemoReact>

```tsx
const regions = { us: 'United States', eu: 'Europe', apac: 'Asia Pacific' };

<Select items={regions} defaultValue="eu">
  <SelectTrigger aria-label="Region">
    <SelectValue placeholder="Select a region" />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="us">United States</SelectItem>
    <SelectItem value="eu">Europe</SelectItem>
    <SelectItem value="apac">Asia Pacific</SelectItem>
  </SelectContent>
</Select>
```

Controlled, with `value` and `onValueChange`:

```tsx
const [region, setRegion] = React.useState<string | null>(null);

<Select items={regions} value={region} onValueChange={setRegion}>
  <SelectTrigger aria-label="Region">
    <SelectValue placeholder="Select a region" />
  </SelectTrigger>
  <SelectContent>{/* …items… */}</SelectContent>
</Select>
```

`disabled` on the root blocks opening and applies the disabled tokens:

```tsx
<Select items={regions} defaultValue="eu" disabled>
  <SelectTrigger aria-label="Region">
    <SelectValue placeholder="Select a region" />
  </SelectTrigger>
  <SelectContent>{/* …items… */}</SelectContent>
</Select>
```

`SelectGroup` + `SelectGroupLabel` split the options into labeled sections, each
divided from the previous one by a top border:

```tsx
<SelectContent>
  <SelectGroup>
    <SelectGroupLabel>Americas</SelectGroupLabel>
    <SelectItem value="us">United States</SelectItem>
  </SelectGroup>
  <SelectGroup>
    <SelectGroupLabel>EMEA</SelectGroupLabel>
    <SelectItem value="eu">Europe</SelectItem>
  </SelectGroup>
</SelectContent>
```

With `multiple`, every row shows a leading checkbox, the popup stays open, and
the value is an array:

```tsx
<Select items={regions} multiple value={regionIds} onValueChange={setRegionIds}>
  <SelectTrigger aria-label="Regions">
    <SelectValue placeholder="Select regions" />
  </SelectTrigger>
  <SelectContent>{/* …items… */}</SelectContent>
</Select>
```
