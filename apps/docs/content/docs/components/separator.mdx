## Usage

```tsx
import { Separator } from '@acronis-platform/ui-react';
```

`Separator` is a 1px rule built on
[Base UI's Separator](https://base-ui.com/react/components/separator), which sets
the `separator` role and `aria-orientation` so the divide is announced rather
than purely visual. It is `horizontal` by default (full width, 1px tall); pass
`orientation="vertical"` for a full-height, 1px-wide rule — that variant needs a
parent with a resolved height, so put it inside a height-bearing flex row.

There is no `--ui-separator-*` token tier: the line uses the shared divider
token `--ui-border-on-surface-border` via the bridged `bg-border` name, so a
brand override follows automatically. Spacing is yours to set with `className`.

Use it to separate groups of content or controls. Don't reach for it purely for
spacing — use margin or padding. Inside a dropdown, group items into
`DropdownMenuGroup`s instead; non-first groups draw their own top border.

## Examples

<DemoReact>
  <SeparatorDemo />
</DemoReact>

A horizontal rule between blocks:

```tsx
<div className="space-y-1">
  <h4 className="text-sm font-medium leading-none">Workloads</h4>
  <p className="text-sm">Manage and protect your devices.</p>
</div>
<Separator className="my-4" />
```

Vertical rules between inline items — note the height on the row:

```tsx
<div className="flex h-5 items-center gap-4 text-sm">
  <div>Backup</div>
  <Separator orientation="vertical" />
  <div>Recovery</div>
  <Separator orientation="vertical" />
  <div>Reports</div>
</div>
```
