## Usage

```tsx
import {
  Pagination,
  PaginationContent,
  PaginationItem,
  PaginationLink,
  PaginationPrevious,
  PaginationNext,
  PaginationEllipsis,
} from '@acronis-platform/ui-react';
```

`Pagination` renders a `<nav role="navigation" aria-label="pagination">` landmark
around a `<ul>` of page controls: `PaginationPrevious` / `PaginationNext`
chevrons, numbered `PaginationLink`s, and `PaginationEllipsis` for a skipped
range. It is markup-only — no Base UI primitive, no internal page state. You wire
each link (`href` or `onClick`) and mark the current page with `isActive`, which
sets `aria-current="page"` and the selected treatment.

There is no `--ui-pagination-*` token tier: the compact square links are styled
from the shared semantic tokens rather than the `Button` variants (whose
min-width tokens don't fit a square link). Page numbers use
`--ui-text-on-surface-primary`, the active page sits on
`--ui-background-surface-active`, inactive links hover to
`--ui-background-surface-hover`, and focus draws a `--ui-focus-primary` ring.

Reach for it when a long list or table is split into pages with direct page
access. Inside a [`DataTable`](/components/data-table) use its built-in
`DataTablePagination` instead; for continuous loading use infinite scroll or a
"Load more" button.

A trail with a current page and a skipped range:

```tsx
<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious href="#" />
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="#">1</PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="#" isActive>
        2
      </PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationEllipsis />
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="#">10</PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationNext href="#" />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```

Client-side paging — the links take any `<a>` attributes, so drive them with
`onClick` instead of `href`:

```tsx
<PaginationLink
  href="#"
  isActive={page === n}
  onClick={(event) => {
    event.preventDefault();
    setPage(n);
  }}
>
  {n}
</PaginationLink>
```

## API Reference

### PaginationLink

`PaginationPrevious` and `PaginationNext` take the same props — they render a
`PaginationLink` with the chevron and the matching `aria-label`.

and `PaginationEllipsis` (`<span>`) accept the standard attributes of the element
