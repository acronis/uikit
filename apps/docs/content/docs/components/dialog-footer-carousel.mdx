## Usage

```tsx
import { DialogFooterCarousel } from '@acronis-platform/ui-react';
```

`DialogFooterCarousel` is the footer bar for [`DialogWelcome`](/components/dialog-welcome)'s
`carousel` layout: a Back/Next/Close action pair flanking a slide-position
indicator with one dot per slide. It takes no `variant`/`state` prop — its
first/middle/last treatment and its dot count/active index are derived from
the ambient `<Carousel>` context's `selectedIndex`/`slideCount` (not
`canScrollPrev`/`canScrollNext`, which stay permanently `true` when the
Carousel loops and would hide the Close button forever).

Its `close` control assumes a `Dialog` ancestor (it composes `Button` with
`DialogClose`). It also requires an ambient `<Carousel>` context provider to
read its position from — that provider isn't part of the public API, so
`DialogFooterCarousel` can't currently be constructed standalone outside of
`DialogWelcome`: pass 2 or more `DialogWelcomeSlide` children to it, and it
composes `DialogFooterCarousel` for you, forwarding the label props below.

## Parts

| Part    | Element (default)                   | Purpose                                                                     |
| ------- | ----------------------------------- | --------------------------------------------------------------------------- |
| `back`  | `button` (`Button`)                 | Scrolls to the earlier slide. Hidden on the first slide.                    |
| `dots`  | `div`                               | One-dot-per-slide position indicator; the active dot's own fill changes color — there is no surrounding container box. |
| `next`  | `button` (`Button`)                 | Scrolls to the later slide. Hidden on the last slide.                       |
| `close` | `button` (`Button` + `DialogClose`) | Closes the ambient Dialog. Shown only on the last slide, in `next`'s place. |

## Localization

There's no i18n library in this repo, so the footer's own visible/accessible
text is overridable via props rather than baked in:

```tsx
<DialogFooterCarousel
  backLabel="Précédent"
  nextLabel="Suivant"
  closeLabel="Fermer"
  positionLabel="Position de la diapositive"
  dotAriaLabel={(index, count) => `Diapositive ${index} sur ${count}`}
/>
```

When used via `DialogWelcome`, pass the same props to it — they're forwarded
straight through.
