## Usage

```tsx
import { InputPassword } from '@acronis-platform/ui-react';
```

`InputPassword` is an [`InputText`](/components/input-text)-shaped field — label
(with a `required` marker), value box, and a `description` or `error` message —
with a show/hide toggle built into the box. Unlike `InputText` it does not wrap
the bare `InputBox`: the design gives it its own `--ui-input-password-*` token
tier down to the box fill and border, so the native `<input>` renders borderless
inside a themed flex container next to the toggle. No Base UI primitive is
involved; the toggle is a
[`ButtonIconInput`](/components/button-icon-input), matching the Figma component
of the same name.

`ref` and `className` target the underlying `<input>`. The label, message, and
required marker are wired to it via `htmlFor`, `aria-describedby`,
`aria-required`, and `aria-invalid`, so the field is self-contained and does not
need a [`Field`](/components/field) wrapper. Visibility is internal state — there
is no controlled `type` or "revealed" prop.

## Examples

A required field with helper text, and the same field in its error state:

<DemoReact>
  <InputPasswordDemo />
</DemoReact>

```tsx
<InputPassword
  label="Password"
  required
  placeholder="Enter a password"
  description="At least 8 characters."
/>

<InputPassword
  label="Password"
  defaultValue="short"
  error="Enter at least 8 characters."
/>
```

The toggle starts with the value masked (`type="password"`) and the crossed-eye
icon; activating it flips the input to `type="text"`, swaps in the plain eye, and
updates `aria-pressed`. `error` reddens the box border, switches the focus ring
to `--ui-focus-error`, puts the toggle in its `error` tone, and replaces the
`description` with the error message.

Disabled disables both the input and the toggle, and applies the disabled tokens
to the box, label, and message:

```tsx
<InputPassword label="Password" defaultValue="hunter2" disabled />
```

The toggle's accessible name is the only string the component supplies itself.
Override both halves for localization:

```tsx
<InputPassword
  label="Contraseña"
  showPasswordLabel="Mostrar contraseña"
  hidePasswordLabel="Ocultar contraseña"
/>
```
