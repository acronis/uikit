## Usage

```tsx
import { Tag } from '@acronis-platform/ui-react';
```

`Tag` renders a `<span>` pill styled by the `--ui-tag-*` tokens: `variant` picks
the container fill, border, label, and icon colors, while geometry — radius,
border width, gap, padding, min/max width, icon size — comes from the shared
`--ui-tag-global-*` tokens. It is presentational and non-interactive; the label
truncates rather than wrapping.

> **`Badge` is an alias of `Tag`.** The legacy generic shadcn `Badge` is replaced
> by the design-system-native `Tag`, which carries its own token tier, icon slot,
> and sizes. `import { Badge } from '@acronis-platform/ui-react'` re-exports `Tag`
> — same props, same variants. Prefer `Tag` in new code.

## Examples

Seven variants, one per semantic role. The default is `neutral`; `ai` paints a
gradient border over a tinted fill:

<DemoReact>
  <TagDemo />
</DemoReact>

```tsx
<Tag variant="info">Info</Tag>
<Tag variant="success">Success</Tag>
<Tag variant="warning">Warning</Tag>
<Tag variant="critical">Critical</Tag>
<Tag variant="danger">Danger</Tag>
<Tag variant="neutral">Neutral</Tag>
<Tag variant="ai">AI</Tag>
```

Pass an `icon` for a 16px leading glyph. Nothing is injected automatically:

```tsx
import { CircleCheckIcon } from '@acronis-platform/icons-react/stroke-mono';

<Tag variant="success" icon={<CircleCheckIcon />}>
  Protected
</Tag>;
```

`size` only changes the height — `default` is 24px, `sm` is 20px; padding is the
same in both:

```tsx
<Tag variant="info">Default</Tag>
<Tag variant="info" size="sm">
  Small
</Tag>
```

For a label the user can remove or toggle, use [`Chip`](/components/chip) — a
`Tag` implies no action.
