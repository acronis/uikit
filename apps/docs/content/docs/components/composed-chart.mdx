## Usage

```tsx
import { ComposedChart } from '@acronis-platform/ui-react';
import type { ChartConfig } from '@acronis-platform/ui-react';
```

`ComposedChart` is a typed recharts composition over the shared
[`Chart`](/components/chart) primitives. Give it `data`, a per-series `config`, and
a `series` list where each entry picks its own render `type` (`bar` / `line` /
`area`) over one shared category axis (`xKey`) — it renders a themed recharts
composed chart with tooltip, legend, axes, and grid, so you never hand-compose
recharts children.

Series colors are supplied by the caller through `config`, keyed by each
`series[].key`: `ComposedChart` turns those into the `--color-<key>` custom
properties its marks paint from. Series render **in the order you list them** —
recharts paints children back-to-front, so later entries sit on top. Order them so
a thin line comes after the bars and areas it should overlay.

Use it to overlay related measures that read better in different shapes (revenue
bars with a profit-margin line, volume bars behind a trend area), or to emphasize
one series against a backdrop of others. When every series is the same kind,
prefer [`BarChart`](/components/bar-chart),
[`LineChart`](/components/line-chart), or [`AreaChart`](/components/area-chart).
This v1 shares a **single Y axis**, so measures with wildly different scales
belong in separate charts. For part-to-whole use
[`PieChart`](/components/pie-chart).

Pair the chart with a text alternative (caption, summary, or adjacent data table)
and give it an accessible name — `aria-label` / `aria-labelledby` pass through to
the wrapper element. Keep either the legend or the tooltip visible (the differing
render types are your second channel), and **call out the shared scale in the
caption** when mixed series differ a lot in magnitude.

> **Design-pending v1**, ported from the demo `ComposedChartPlayground`. There is
> no chart token tier yet, so the example colors reference the shared semantic
> `--ui-*` brand/status tokens — a dedicated `--ui-chart-*` data-viz palette is
> pending an upstream design pass. `--ui-background-status-strong-*` is chromatic
> in every brand; `--ui-background-brand-secondary` is brand-dependent, so it is
> not color-stable across brands until the real palette lands. An area series'
> `fillOpacity` lowers its effective contrast — check yours against the surface.

## Examples

  <ComposedChartDemo />
</DemoReact>

The classic combo — bars for a quantity with a line for a related trend:

```tsx
const data = [
  { month: 'Jan', revenue: 4200, forecast: 3800, profit: 2400 },
  { month: 'Feb', revenue: 3100, forecast: 2900, profit: 1400 },
  { month: 'Mar', revenue: 6500, forecast: 5200, profit: 4800 },
];

const config = {
  revenue: { label: 'Revenue', color: 'var(--ui-background-brand-secondary)' },
  forecast: { label: 'Forecast', color: 'var(--ui-background-status-strong-danger)' },
  profit: { label: 'Profit', color: 'var(--ui-background-status-strong-success)' },
} satisfies ChartConfig;

<ComposedChart
  config={config}
  data={data}
  series={[
    { key: 'revenue', type: 'bar' },
    { key: 'profit', type: 'line' },
  ]}
  xKey="month"
  className="h-[320px] w-[560px]"
/>;
```

Mix all three render types. Because paint order follows the array, list them
back-to-front — bar, then area, then line — so the thin line lands on top:

```tsx
<ComposedChart
  config={config}
  data={data}
  series={[
    { key: 'revenue', type: 'bar' },
    { key: 'forecast', type: 'area' },
    { key: 'profit', type: 'line' },
  ]}
  xKey="month"
/>
```

Reordering the same entries reorders the painted layers — here the bars cover the
area:

```tsx
<ComposedChart
  config={config}
  data={data}
  series={[
    { key: 'forecast', type: 'area' },
    { key: 'revenue', type: 'bar' },
  ]}
  xKey="month"
/>
```

Tune the shared knobs with `curve` (line and area interpolation), `barRadius`
(rounding on the bars' growing end), `fillOpacity` (area fills), and the
`showGrid` / `showTooltip` / `showLegend` toggles:

```tsx
<ComposedChart
  config={config}
  data={data}
  series={[
    { key: 'revenue', type: 'bar' },
    { key: 'forecast', type: 'area' },
  ]}
  xKey="month"
  curve="linear"
  barRadius={0}
  fillOpacity={0.15}
/>
```

Add axis titles and a y-axis unit suffix with `xAxisLabel` / `yAxisLabel` /
`yUnit` (the x-axis is categorical). The titles inherit the theme token:

```tsx
<ComposedChart
  config={config}
  data={data}
  series={[
    { key: 'revenue', type: 'bar' },
    { key: 'profit', type: 'line' },
  ]}
  xKey="month"
  xAxisLabel="Month"
  yAxisLabel="Amount"
  yUnit="$"
/>
```

Replace the tooltip with a configured `ChartTooltipContent` — imported from the
same library, so you still never compose recharts yourself. Its `formatter`
renders each row and `labelFormatter` the header:

```tsx
import { ComposedChart, ChartTooltipContent } from '@acronis-platform/ui-react';

<ComposedChart
  config={config}
  data={data}
  series={[
    { key: 'revenue', type: 'bar' },
    { key: 'profit', type: 'line' },
  ]}
  xKey="month"
  tooltipContent={
    <ChartTooltipContent
      labelFormatter={(label) => `${label} · fiscal Q3`}
      formatter={(value, name) => `${name}: $${value.toLocaleString()}`}
    />
  }
/>;
```
