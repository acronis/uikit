## Usage

```tsx
import {
  Combobox,
  ComboboxInput,
  ComboboxContent,
  ComboboxList,
  ComboboxItem,
  ComboboxEmpty,
  ComboboxGroup,
  ComboboxGroupLabel,
} from '@acronis-platform/ui-react';
```

`Combobox` is a searchable select: `ComboboxInput` renders the field box (a
typeable input, an optional clear button, and a chevron toggle) and
`ComboboxContent` is the portaled dropdown holding a `ComboboxList` of
`ComboboxItem`s plus a `ComboboxEmpty` fallback. The root holds the `items` and
the value and filters the items by the typed text; the WAI-ARIA combobox pattern,
keyboard navigation, and focus management come from Base UI's
[`Combobox`](https://base-ui.com/react/components/combobox) primitive. There is
no `--ui-combobox-*` token tier yet — it reuses the `--ui-input-select-*` tokens,
so the field box, dropdown surface, and rows match
[`InputSelect`](/components/input-select), the non-typeable sibling. Use
`Combobox` when the list is long enough that the user should type to narrow it.

Pair the field with a label: wrap it in a [`Field`](/components/field) with a
`FieldLabel`, or set `aria-label` on `ComboboxInput`.

## Examples

`items` of `{ value, label }` objects have their label and value extracted
automatically. `ComboboxList` children may be a function `(item) => …` that maps
over the **filtered** items, and `clearable` adds the clear (✕) button:

<DemoReact>
  <ComboboxDemo />
</DemoReact>

```tsx
type Framework = { value: string; label: string };

const frameworks: Framework[] = [
  { value: 'next', label: 'Next.js' },
  { value: 'sveltekit', label: 'SvelteKit' },
  { value: 'nuxt', label: 'Nuxt.js' },
  { value: 'remix', label: 'Remix' },
  { value: 'astro', label: 'Astro' },
];

<Combobox items={frameworks}>
  <ComboboxInput placeholder="Search framework…" clearable />
  <ComboboxContent>
    <ComboboxEmpty>No framework found.</ComboboxEmpty>
    <ComboboxList>
      {(item: Framework) => (
        <ComboboxItem key={item.value} value={item}>
          {item.label}
        </ComboboxItem>
      )}
    </ComboboxList>
  </ComboboxContent>
</Combobox>
```

Static children work too, when the option list is written out rather than mapped:

```tsx
<Combobox items={frameworks}>
  <ComboboxInput aria-label="Framework" placeholder="Search framework…" />
  <ComboboxContent>
    <ComboboxEmpty>No framework found.</ComboboxEmpty>
    <ComboboxList>
      <ComboboxItem value="next">Next.js</ComboboxItem>
      <ComboboxItem value="astro">Astro</ComboboxItem>
    </ComboboxList>
  </ComboboxContent>
</Combobox>
```

Controlled selection, with `value` and `onValueChange`:

```tsx
const [framework, setFramework] = React.useState<Framework | null>(null);

<Combobox items={frameworks} value={framework} onValueChange={setFramework}>
  {/* …input + content… */}
</Combobox>
```

`multiple` selects several items — each selected row keeps a trailing check and
the value is an array:

```tsx
<Combobox items={frameworks} multiple value={selected} onValueChange={setSelected}>
  {/* …input + content… */}
</Combobox>
```

`disabled` on the root makes the box inert and applies the disabled tokens, and
`aria-invalid` on the input switches the box to its error border and focus ring:

```tsx
<Combobox items={frameworks} disabled>
  <ComboboxInput aria-label="Framework" placeholder="Search framework…" />
  <ComboboxContent>{/* …list… */}</ComboboxContent>
</Combobox>

<Combobox items={frameworks}>
  <ComboboxInput aria-label="Framework" aria-invalid placeholder="Search framework…" />
  <ComboboxContent>{/* …list… */}</ComboboxContent>
</Combobox>
```

`ComboboxGroup` + `ComboboxGroupLabel` head a block of related options:

```tsx
<ComboboxContent>
  <ComboboxList>
    <ComboboxGroup>
      <ComboboxGroupLabel>React</ComboboxGroupLabel>
      <ComboboxItem value="next">Next.js</ComboboxItem>
      <ComboboxItem value="remix">Remix</ComboboxItem>
    </ComboboxGroup>
  </ComboboxList>
</ComboboxContent>
```

When the root's `items` are group-shaped instead of flat, pass each group's own
`items` to `ComboboxGroup` so a mapped `ComboboxList` child renders from it.
