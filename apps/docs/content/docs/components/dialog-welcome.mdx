## Usage

```tsx
import { DialogWelcome, DialogWelcomeSlide } from '@acronis-platform/ui-react';
```

`DialogWelcome` is a second Dialog "recipe" alongside [`Dialog`](/components/dialog):
headerless, its body is an image plus a centered title/description. By
default, its layout is derived from how many `DialogWelcomeSlide` children you
pass:

- **Exactly one** child renders the **single** layout — a call-to-action
  button and a "Close" button, stacked below the text.
- **2–5** children render the **carousel** layout — each slide keeps its own
  image/text, navigated by [`DialogFooterCarousel`](/components/dialog-footer-carousel)
  (Back/Next/Close + a one-dot-per-slide position indicator).

An optional `variant?: 'carousel' | 'single'` prop overrides that
count-derived default: `variant="carousel"` keeps the carousel chrome for a
single slide, and `variant="single"` forces the single layout, dropping any
slides beyond the first. Omit `variant` to keep the count-derived behavior.

```tsx
<DialogWelcome
  open={open}
  onOpenChange={setOpen}
  aria-label="Product tour"
  opts={{ startIndex }}
  setApi={(api) => api?.on('select', () => syncUrl(api.selectedScrollSnap()))}
>
  {/* … */}
</DialogWelcome>
```

## Slide count

`children` must resolve to between 1 and 5 `DialogWelcomeSlide`s — exactly one
selects the single layout, 2 or more select the carousel layout. Outside the
[1, 5] range this is handled silently: 0 real slides render nothing, and above
5 only the first 5 children render, dropping the rest.

## Parts

| Part                   | Purpose                                                                                             |
| ---------------------- | --------------------------------------------------------------------------------------------------- |
| `DialogWelcomeSlide`   | A slide's image + centered title/description.                                                       |
| CTA + Close buttons    | Single layout only — a primary call-to-action button and a ghost "Close" link, stacked/centered.    |
| `DialogFooterCarousel` | Carousel layout only — the Back/Next/Close + dot-indicator footer, driving navigation from context. |
