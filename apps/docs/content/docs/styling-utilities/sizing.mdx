[`@acronis-platform/tokens-pd`](/packages/tokens-pd) generates a width/height
utility grammar from the **same** spacing scale that backs the
[margin/padding/gap utilities](/styling-utilities/spacing) (`css/default.css`),
so both Tailwind and non-Tailwind
[`@acronis-platform/ui-react`](/getting-started) consumers can size elements
from the same scale instead of arbitrary values.

<Callout type="info">
  Sizing shares the spacing scale's `--ui-gap-<step>` custom properties — it
  isn't a separate token, and it isn't brand-dependent.
</Callout>

## Utility classes

Loading `css/default.css` (bundled by `@acronis-platform/ui-react/styles`) also
ships `.ui-{property}-{step}` classes for every step above — usable directly in
markup with no Tailwind build step:

```tsx
<div className="ui-w-64 ui-h-32">
  <span className="ui-max-w-96">Item</span>
</div>
```

| Prefix    | Property     |
| --------- | ------------ |
| `w`       | `width`      |
| `h`       | `height`     |
| `min-w`   | `min-width`  |
| `min-h`   | `min-height` |
| `max-w`   | `max-width`  |
| `max-h`   | `max-height` |

There's also one static, non-scale utility:

```tsx
<div className="ui-max-w-full" />
```

## Fractions

Not token-driven — a fixed, finite set copied verbatim from Tailwind's own
default fraction scale (halves, thirds, quarters, fifths, sixths, twelfths),
applied to **both** width and height:

```tsx
<div className="ui-w-1/2 ui-h-1/3" />
```

Selectors escape the `/` (`.ui-w-1\/2`) — this is invisible from markup, an
unescaped `className="ui-w-1/2"` matches it exactly like any Tailwind
fraction class does.

<Callout type="warn">
  Fraction labels are **not reduced**: `.ui-w-2/4` and `.ui-w-1/2` both render
  `50%` but are separate classes, matching Tailwind's own convention.
</Callout>

## Named max-width scale

Also not token-driven — Tailwind's own bounded `xs`…`7xl` scale, copied
verbatim (values are Tailwind's defaults, rem × 16px):

```tsx
<div className="ui-max-w-md" />
```

`ui-max-w-xs` (320px), `sm` (384px), `md` (448px), `lg` (512px), `xl`
(576px), `2xl` (672px), `3xl` (768px), `4xl` (896px), `5xl` (1024px), `6xl`
(1152px), `7xl` (1280px).

<Callout type="warn">
  All of the above is generated from `@acronis-platform/design-tokens` by the
  `tools/style-dictionary` pipeline and committed to git. Never hand-edit
  `css/default.css` directly — change the upstream token and rebuild.
</Callout>
