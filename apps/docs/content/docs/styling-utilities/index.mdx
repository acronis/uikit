---
title: Styling Utilities
description: Framework-agnostic spacing, sizing, layout utility classes and viewport breakpoints shipped alongside the design tokens.
---

**Styling utilities** are small, generated CSS building blocks that sit next to
the token system — usable whether or not a consumer extends the Tailwind
preset.

- [Spacing](/styling-utilities/spacing) — `.ui-p-*`/`.ui-m-*`/`.ui-gap-*`
  padding, margin, and gap classes generated from the design system's spacing
  scale.
- [Sizing](/styling-utilities/sizing) — `.ui-w-*`/`.ui-h-*` (+ min/max) width
  and height classes generated from the same spacing scale.
- [Layout](/styling-utilities/layout) — static `.ui-*` flex, grid, alignment,
  and text-flow (wrapping/overflow) classes mirroring Tailwind's own bounded
  utility groups.
- [Breakpoints](/styling-utilities/breakpoints) — the viewport breakpoint scale,
  as Tailwind `@theme` values, `--ui-breakpoint-*` CSS variables, and JS
  constants.

For color, typography, and component tokens, see
[Token reference](/token-reference) and [Typography](/typography).
