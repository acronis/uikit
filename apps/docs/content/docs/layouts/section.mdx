## Usage

```tsx
import {
  Section,
  SectionHeader,
  SectionTitle,
  SectionDescription,
  SectionContent,
} from '@acronis-platform/ui-react';
```

`Section` groups a page area under a heading: a native `<section>` with an
optional `SectionHeader` (an `<h2>` `SectionTitle` plus a `SectionDescription`
paragraph) over a `SectionContent` body. All five parts are plain semantic
wrappers with vertical spacing — nothing is positioned or sized for you.

There is no `--ui-section-*` token tier. The only color the block paints is the
description, which uses `--ui-text-on-surface-secondary` (via the bridged
`text-muted-foreground`); the title inherits the surrounding foreground.

> Design-pending v1, ported 1:1 from the legacy `shadcn-uikit` section.

## Examples

<DemoReact>
  <SectionDemo />
</DemoReact>

```tsx
<Section>
  <SectionHeader>
    <SectionTitle>Backup plans</SectionTitle>
    <SectionDescription>
      Manage how your workloads are backed up and retained.
    </SectionDescription>
  </SectionHeader>
  <SectionContent>{children}</SectionContent>
</Section>
```

The header is optional — drop it when the surrounding page already names the
area, and use `Section` for grouping alone:

```tsx
<Section>
  <SectionContent>
    <Grid cols={3}>{widgets}</Grid>
  </SectionContent>
</Section>
```

Stack several sections down a settings page. Give each one an accessible name so
they are distinguishable — the `SectionTitle` heading usually does that; set
`aria-labelledby` or `aria-label` when there is no visible title:

```tsx
<Stack gap="xl">
  <Section aria-label="General">
    <SectionContent>…</SectionContent>
  </Section>
  <Section>
    <SectionHeader>
      <SectionTitle>Notifications</SectionTitle>
    </SectionHeader>
    <SectionContent>…</SectionContent>
  </Section>
</Stack>
```

`SectionTitle` is fixed at `<h2>`. Check it fits the page's document outline —
`PageHeaderTitle` is the `<h1>` above it — and for pure spacing with no heading
use [`Stack`](/layouts/stack) or [`Grid`](/layouts/grid) instead.

## Parts

| Export               | Element   | Purpose                          |
| -------------------- | --------- | -------------------------------- |
| `Section`            | `section` | The block itself.                |
| `SectionHeader`      | `div`     | Groups the title + description.  |
| `SectionTitle`       | `h2`      | The section heading.             |
| `SectionDescription` | `p`       | Muted supporting text.           |
| `SectionContent`     | `div`     | The body.                        |

## API Reference

`Section`, `SectionHeader`, `SectionTitle`, `SectionDescription`, and
`SectionContent` declare no props of their own — each accepts the native
attributes of the element it renders (`section`, `div`, `h2`, `p`, `div`),
including `className`, and forwards its `ref` to that element.
