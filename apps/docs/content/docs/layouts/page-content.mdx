## Usage

```tsx
import { PageContent } from '@acronis-platform/ui-react';
```

`PageContent` is the standard page gutter: a single `<div>` that grows to fill
its parent and applies the page padding. It has **no tokens of its own** — no
color, border, or surface, just layout — so the page canvas comes from whatever
it sits on.

It renders a `<div>` rather than a `<main>` on purpose, so it nests inside
[`AppShellMain`](/layouts/app-shell) without adding a second `main` landmark.
Used outside the App Shell, wrap it in your own `<main>`. `PageContent` is the
gutter, not the scroll container — scrolling belongs to `AppShellMain`.

## Examples

<DemoReact>
  <PageContentDemo />
</DemoReact>

```tsx
<AppShellMain>
  <PageContent>
    <PageHeader>
      <PageHeaderRow>
        <PageHeaderTitle>Reports</PageHeaderTitle>
      </PageHeaderRow>
    </PageHeader>
    {children}
  </PageContent>
</AppShellMain>
```

Standalone, supply the landmark yourself:

```tsx
<main>
  <PageContent>{children}</PageContent>
</main>
```

Override the padding with `className` when a page needs a flush edge — for
example a full-bleed table or map:

```tsx
<PageContent className="p-0">
  <DataTable … />
</PageContent>
```
